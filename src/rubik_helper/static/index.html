Sauvegardes

Une sauvegarde garde l'état saisi, la solution calculée et l'endroit où vous en êtes dans le lecteur. Une fois enregistrée ou reprise, elle se met à jour toute seule à chaque coup : vous pouvez fermer l'onglet et reprendre plus tard. Les sauvegardes restent dans ce navigateur, sur cet appareil ; « Exporter » produit un fichier à importer sur un autre appareil.

Choisissez une couleur puis cliquez sur les facettes, dans le patron ou sur la vue 3D. Maj + clic (ou appui long au doigt) remplit toute la face.

Présentez une face à la caméra en suivant le gabarit, puis capturez.

Après capture, corrigez les erreurs éventuelles en peignant sur le patron avant de valider. Quand toutes les faces sont capturées, la relecture globale répartit les couleurs en tenant compte du nombre de facettes de chaque couleur.

Étalonnage des couleurs (pipette)

Les teintes varient selon le fabricant. Choisissez une couleur ci-dessous, puis touchez une facette de cette couleur sur l'image de la caméra. L'étalonnage est conservé pour ce type de puzzle sur cet appareil.

Notation acceptée
Glisser pour tourner, molette ou pincement pour zoomer.
Saisissez l'état du puzzle puis lancez la résolution.
